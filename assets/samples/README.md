Writing sample PDFs go here.

Each sample card in index.html links to one file in this folder. The filename in
the link must match exactly — URLs on GitHub Pages are case-sensitive, so use
lowercase-with-hyphens and no spaces.

Currently linked from index.html:

  target-product-profile.pdf
  risk-management-plan.pdf
  informed-consent-form.pdf
  quality-manual.pdf

To add or replace a sample, drop the PDF here with a lowercase-hyphenated name
and update the matching href in index.html.
